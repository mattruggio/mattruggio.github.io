ytm

Export a public YouTube Music playlist as JSON: a tracklist shaped for music, and the raw YouTube API responses it was built from. It runs in your browser with your own YouTube Data API key, and talks to nothing but Google's API.

{%- comment -%} The key steps render open without JavaScript, and the script folds them behind a toggle only once a key is saved in this browser. A first-time visitor always sees them; a returning one is not made to scroll past them. Everything the script touches is addressed by data-ytm attributes, the same seam /blackjack/ uses with data-bj. {%- endcomment -%}

Get an API key

Free, and a few minutes of clicking. No billing account is needed, and the key stays in this browser.

  1. Sign in to the Google Cloud Console and create a project. Any name works.
  2. With that project selected, open YouTube Data API v3 and click Enable.
  3. Go to Credentials, click Create credentials, and choose API key.
  4. Restrict the key, so that it is useless to anyone who finds it:
    • Under Application restrictions, choose Websites and add https://rugg.io/*.
    • Under API restrictions, choose Restrict key and select only YouTube Data API v3.
  5. Copy the key and paste it below.

Each key gets 10,000 quota units a day, and a playlist costs about one unit per 50 tracks. Usage is on the project's quotas page. Google's own walkthrough is in the getting started guide.
